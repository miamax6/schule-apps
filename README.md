# schule-apps

Petites applications web pour la classe (HTML, CSS et JavaScript dans un seul fichier, sans ressource externe).

| Application | Adresse |
|---|---|
| Carnet de classe | `carnet-de-classe/` |

## Données
Aucune donnée d'élève n'est stockée dans ce dépôt ni envoyée sur Internet.
Chaque application enregistre ses données dans le navigateur de l'appareil utilisé.
Les sauvegardes (.json), exports (.csv) et PDF ne doivent jamais être ajoutés ici (voir `.gitignore`).

## Publication
GitHub Pages : branche `main`, dossier `/ (root)`.

## Ajouter une application
Créer un dossier `nom-de-l-appli/` contenant un `index.html`, puis l'ajouter à la liste de `index.html` à la racine.
